# Cadastros e clientes

Comece cadastrando os dados que sua empresa usa no atendimento: clientes, equipamentos, profissionais e serviços.

## Fluxo recomendado

1. Cadastre o cliente com telefone, endereço e demais dados de contato.
2. Adicione os equipamentos desse cliente, incluindo marca, modelo, número de série e local de instalação quando disponível.
3. Cadastre os serviços oferecidos e defina duração, preço e disponibilidade para agendamento online.
4. Cadastre os profissionais e vincule os serviços que cada pessoa pode executar.

Manter esses dados atualizados deixa a criação de OS, orçamentos e agendamentos mais rápida.
