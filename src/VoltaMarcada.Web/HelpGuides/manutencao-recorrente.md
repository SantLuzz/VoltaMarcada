# Manutenção recorrente

Após concluir uma OS, use a recomendação de manutenção para criar uma oportunidade de retorno.

## Fluxo de retorno

1. Defina intervalo ou data recomendada ao concluir a OS.
2. Acompanhe oportunidades vencidas e próximas do vencimento.
3. Entre em contato com o cliente e envie o link contextual quando necessário.
4. O cliente informa uma preferência de data e horário.
5. A empresa avalia a solicitação, agenda a visita ou prepara um orçamento.
