# Quote PDF Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver secure authenticated and public downloads of server-generated quote PDFs.

**Architecture:** Application prepares a framework-neutral `QuotePdfDocument` only after enforcing tenant or public-token access, then delegates byte generation to `IQuotePdfGenerator`. Infrastructure implements that interface with QuestPDF and Web turns successful use-case results into file responses and download actions.

**Tech Stack:** .NET 10, C#, ASP.NET Core minimal APIs and Blazor, EF Core/PostgreSQL, QuestPDF 2026.8.0, xUnit.

**Spec:** `docs/superpowers/specs/2026-09-01-quote-pdf-design.md`

## Global Constraints

- Source code, logs, tests, and technical documentation use English; Brazilian Portuguese is reserved for UI and HTTP error text.
- `Company` is the tenant boundary. Authenticated PDF access obtains the company from `ICurrentCompany`; never accept `CompanyId` from a browser value.
- Domain and Application must not reference QuestPDF, ASP.NET Core response types, or direct clock APIs.
- Public access receives only a raw token at the boundary, hashes it before repository lookup, and never logs or persists the raw token.
- Generated PDFs are on-demand byte responses. Do not add PDF storage, database columns, migrations, attachments, or background jobs.
- Use `TimeProvider` for public-token expiry and quote-expiry decisions.
- Keep optional logo retrieval non-fatal: an unavailable logo produces a PDF without a logo.
- QuestPDF 2026.8.0 is confined to Infrastructure. Set the correct QuestPDF license type for the deployment before production use.

- [ ] **Step 3: Implement one public-token access service**

Create an application-internal scoped service with this behavior:

```csharp
public async Task<Quote?> ResolveAsync(string? token, CancellationToken cancellationToken = default)
{
    if (string.IsNullOrWhiteSpace(token)) return null;

    var quote = await quotes.GetForPublicTokenAsync(PublicTokenGenerator.Hash(token), cancellationToken);
    var now = timeProvider.GetUtcNow();
    if (quote is null || quote.PublicTokenExpiresAtUtc <= now) return null;
    if (quote.ExpireIfPast(DateOnly.FromDateTime(now.UtcDateTime), now))
    {
        await quotes.SaveChangesAsync(cancellationToken);
        return null;
    }

    return quote.Status is QuoteStatus.Sent or QuoteStatus.Approved or QuoteStatus.Rejected
        ? quote
        : null;
}
```

Register `PublicQuoteAccessService` as scoped. Change `GetPublicQuoteUseCase` to call it before reading the company and mapping `PublicQuoteDto`; remove its duplicated raw-token checks. This preserves the public page behavior while making expiration persistence explicit.

- [ ] **Step 4: Implement the document factory with safe data selection**

`QuotePdfDocumentFactory.CreateAsync(Quote quote, CancellationToken cancellationToken)` must:

1. load `CompanyQuotePdfProfile` by `quote.CompanyId` and the customer with `GetForCompanyAsync(quote.CustomerId, quote.CompanyId)`;
2. return `null` if either record is missing;
3. attempt `IFileStorage.GetAsync(profile.LogoKey, cancellationToken)` only for a non-empty logo key;

6. map no IDs, raw token, service-request information, or internal history into the document.

The factory must preserve the quote's stored arithmetic values and pass a read-only line collection to the document record.
