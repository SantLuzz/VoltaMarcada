# Solicitações públicas

A página pública recebe a preferência do cliente. Ela não confirma automaticamente o atendimento.

## Como tratar uma solicitação

1. Confira cliente, serviço, data e horário preferidos.
2. Verifique os equipamentos vinculados ao cliente.
3. Analise a disponibilidade dos profissionais qualificados.
4. Escolha entre preparar um orçamento ou agendar uma visita.
5. Confirme a próxima etapa e acompanhe o status na agenda.

O profissional é definido internamente; ele nunca é exposto na solicitação pública.
