# Equipamentos

Cada equipamento pertence a um cliente e concentra o histórico de atendimentos e manutenções futuras.

## Como usar

1. Abra o cliente responsável pelo equipamento.
2. Cadastre tipo, fabricante, modelo e os dados de identificação disponíveis.
3. Ao criar uma OS ou orçamento, selecione o equipamento no item de serviço correspondente.
4. Quando houver mais de um equipamento envolvido, adicione itens para cada um deles.

O histórico e as oportunidades de manutenção ajudam a acompanhar retornos no equipamento correto.
